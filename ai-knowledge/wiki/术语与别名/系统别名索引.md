# 系统别名索引

| 需求文档中的叫法 | 标准系统名 | 说明 |
|---|---|---|
| CRM | CRM系统 | 客户主档和客户等级上游 |
| 主档平台 | CRM系统 | 历史文档中的旧叫法 |
| 计费 | 计费平台 | 账单和欠费上游 |
| 账务平台 | 计费平台 | 部分业务人员口语 |
| 客户中心 | 客户中心服务 | 本地统一客户视图服务 |
| 门户 | 销售门户 | 销售前台系统 |

## 固定映射规则

1. 需求里出现“主档”时，默认优先指向 `CRM系统`，除非上下文明确是本地镜像表。
2. 需求里出现“账务状态”或“欠费等级”时，默认优先指向 `计费平台`。
3. 需求里出现“客户中心接口”时，默认指向 `客户中心服务` 暴露的查询接口，而不是 CRM 接口。

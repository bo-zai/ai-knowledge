# 客户统一查询接口

## 接口职责

为销售门户提供统一客户查询和筛选能力。

## 关键返回字段

| 字段 | 来源 |
|---|---|
| customerId | CRM系统 |
| customerName | CRM系统 |
| customerLevel | CRM系统 |
| customerSegment | CRM系统 |
| overdueLevel | 计费平台 |
| localSalesTag | 客户中心服务 |

## 高频变更

1. 新增上游字段暴露到查询结果。
2. 新增筛选参数。
3. 调整本地衍生字段展示。

## 不应承担的职责

1. 不定义上游字段语义。
2. 不直接访问 CRM 或计费平台原始接口。

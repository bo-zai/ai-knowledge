# 客户主档

## 对象定义

客户主档指客户基础身份和主属性集合，包含客户编号、名称、联系方式、等级、分群等字段。

## 事实来源

| 字段 | 来源系统 | 本地是否可重定义 |
|---|---|---|
| customerId | CRM系统 | 否 |
| customerName | CRM系统 | 否 |
| contactPhone | CRM系统 | 否 |
| customerLevel | CRM系统 | 否 |
| customerSegment | CRM系统 | 否 |
| localSalesTag | 客户中心服务 | 是 |

## 本地存储身份

客户中心服务中的 `customer_view` 表是统一查询视图，不是客户主档定义中心。

## 需求判断

1. 需求要求新增 CRM 字段到页面时，优先走同步与视图扩展。
2. 需求要求修改客户主档字段语义时，优先判断应由 CRM 实现。

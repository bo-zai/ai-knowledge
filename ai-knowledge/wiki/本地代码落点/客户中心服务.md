# 客户中心服务

## 服务职责

1. 接入 CRM 客户字段。
2. 接入计费平台欠费字段。
3. 维护统一客户视图。
4. 对销售门户提供统一查询接口。

## 关键模块

| 模块 | 作用 |
|---|---|
| crm-adapter | CRM 接口和事件适配 |
| billing-adapter | 计费接口适配 |
| customer-sync | 字段映射、落库、幂等 |
| customer-view | 统一视图拼装 |
| customer-api | 查询接口暴露 |

## 高频改动点

1. 上游新增字段：`customer-sync` + `customer-view`
2. 查询接口新增返回字段：`customer-view` + `customer-api`
3. 新增筛选条件：`customer-view` + `customer-api`

## 慎改区域

1. 不在 `customer-api` 写上游字段映射逻辑。
2. 不在 `customer-view` 重算上游规则。

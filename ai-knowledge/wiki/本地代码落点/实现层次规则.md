# 实现层次规则

## 层次边界

| 层次 | 职责 | 不应承担的职责 |
|---|---|---|
| adapter | 对接上游接口或事件 | 不做业务规则判断 |
| sync | 字段映射、幂等、落库 | 不做页面展示逻辑 |
| view | 统一查询视图拼装 | 不定义上游规则 |
| api | 参数校验和接口暴露 | 不写字段映射和视图拼装 |

## 高频需求落层

1. 上游新增字段：`adapter` + `sync` + `view`
2. 查询接口增加返回字段：`view` + `api`
3. 页面新增筛选条件：`view` + `api`，门户单独改 UI

## 常见错误

1. 在 `api` 层补上游字段映射。
2. 在 `view` 层重算 CRM 客户等级。

# Requirement Case

## 背景

这个 case 不是从正式 PRD 抽取，而是从现有代码基线反推出的“需求理解测试样例”。

## 需求文本

商品列表接口需要支持按关键字搜索，并在登录用户发起搜索时记录搜索词，为后续搜索历史能力提供基础。

Agent 在阅读这份需求时，至少要判断清楚：

- 关键字到底作用于哪个字段
- 登录边界是否强制
- 搜索历史是在什么条件下写入
- 这次改动应该改 controller、service、SQL 还是共享模型
- 当前验证覆盖够不够

## 评测目的

验证 Agent 是否能依赖沉淀后的知识对象，而不是依赖猜测，稳定产出正确的 change plan。

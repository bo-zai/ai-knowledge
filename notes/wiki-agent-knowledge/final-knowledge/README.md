# Final Knowledge

这个目录保留给最终稳定知识对象。

## 什么能放这里

- `TERM-*`
- `SYS-*`
- `OWN-*`
- `CON-*`
- `MOD-*`
- `VER-*`
- `OPEN-*`
- 后续如果验证有效，再加入 `FLOW-*`、`STATE-*`、`INV-*`、`DEC-*`

## 放入条件

一个对象进入这里前，至少满足：

1. 有一手证据
2. 有明确 `task_triggers`
3. 有明确 `decision_points`
4. 在真实需求评测里证明有价值
5. 没有和现有对象冲突

## 不能放这里的内容

- 方法论说明
- 模板
- 设计讨论
- 需求 plan
- gold case
- claim candidates
- 取证笔记

- 我们不再只有设计方法和试点材料
